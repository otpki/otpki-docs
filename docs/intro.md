OTPKI is an enterprise public key infrastructure platform for managing certificate authorities, certificate issuance, enrollment workflows, revocation, validation, key management, and related operational services.

This documentation site is intended for administrators, operators, integrators, and developers who need to deploy, configure, operate, or integrate with OTPKI.

## What You Will Find Here

- Getting started guidance for new deployments
- Reference material for configuration and platform behavior
- Links to API documentation exposed by the OTPKI UI

## Start Here

- Go to [Getting Started](./getting-started.md) for initial setup and onboarding content
- Go to [Reference](./reference.md) for technical details and deeper documentation
- Use the API Reference link in the navigation to open the generated OpenAPI documentation

## Documentation Scope

This site will grow to cover the major OTPKI domains, including issuance, enrollment, validation, authentication, and platform administration.
