# CRLs

CRLs will be generated for any CA configured with a non-zero (default) validity period.  A task is started on behalf of any CA that will run on this interval to generate and store the CRL.  
Further, if a Publisher is configured for this CA to publish its CRLs an additional task will fire to publish the recently generated CRL.

`*` Delta CRLs not yet supported.
