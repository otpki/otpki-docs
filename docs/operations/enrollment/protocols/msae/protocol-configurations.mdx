## Protocol Configuration

The Protocol Configuration section defines the basic settings for the Auto Enrollment profile.

<DocScreenshot
    alt="MSAE protocol configuration settings"
    src={msaeProtocolConfiguration}
/>

### Name

The name of the Auto Enrollment configuration.

### Certificate Authority

The Certificate Authority used to issue certificates for this profile.

## LDAP Configuration

The LDAP Configuration section defines how the system connects to Active Directory.

<DocScreenshot
    alt="MSAE LDAP configuration settings"
    src={msaeLdapConfiguration}
/>

### LDAP Domain Controller

The hostname or address of the LDAP domain controller.

### LDAP Port

The LDAP port used for the connection.

### LDAP Start TLS

Enables StartTLS for LDAP connections.

### LDAP Use LDAPS

Enables secure LDAP using LDAPS.

### LDAP AD Polling Interval

Defines how often Active Directory is checked for updates.

### LDAP Service Account Username

The username for the LDAP service account.

### LDAP Service Account Password

The password for the LDAP service account.

### Test LDAP Config

Tests the LDAP configuration before saving the profile.

## Template Mapping

The Template Mapping section maps certificate templates to End Entity and Certificate Profiles.

<DocScreenshot
    alt="MSAE template mapping settings"
    src={msaeTemplateMapping}
/>

### Certificate Template ID

The Active Directory certificate template identifier.

### End Entity Profile

The End Entity Profile associated with the template.

### Certificate Profile

The Certificate Profile associated with the template.

### Test LDAP Config

Tests the LDAP configuration and validates the connection before saving the profile.
