For Soft DB KMS, there is no driver-specific configuration data stored in the
key storage configuration itself. When an **Encryption Key** is selected, OTPKI
uses it to encrypt the key data stored for each Soft DB KMS key, which is the
private key material.

<ActivationSection screenshot={activationScreenshot} />

For Soft DB KMS, this is especially useful because there is no external device
PIN. It gives you a simple password-style check before the configuration is
active.
