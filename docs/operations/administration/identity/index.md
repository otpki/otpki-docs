This section covers how OTPKI represents and manages the people and external systems that authenticate to it.

## Identity Areas

- [Users](./users) - manage individual user accounts.
- [Roles](./roles) - manage reusable bundles of permissions assigned to users.
- [Groups](./groups) - manage reusable collections of users, used by features like approval workflows.
- [Identity Providers](./identity-providers) - configure external OIDC providers that authenticate users into OTPKI.
